# Select connection strings by value

A Connector may declare value selectors (`prefixes` and `contains`) on positional operands and on flag values, so an input that normally is Scope Selection becomes Explicit Connection Input when its value is a connection string, such as psql's `-d`, `--dbname`, or database operand holding `postgres://...` or `host=... dbname=...`. The selectors are fixed string tests on top-level or field inputs; `onInput` stays a fixed `passthrough` or `override`, and a value-matched selector may share its flag or position with one plain selector because any passthrough match wins. This supersedes the earlier rule that psql's `-d` and `--dbname` always override only the default database: that rule let a caller's host combine with the Active Context's password and SSL mode, which ADR 0010 forbids. We rejected conditional `onInput` expressions and CLI-specific Go code because literal prefixes and substrings cover libpq's own connection-string test and keep definitions declarative.
